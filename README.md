### ALGO-000142: Efficient sampling near the graph-coloring uniqueness threshold
- **Subfield:** Approximate counting, sampling, and average-case complexity
- **Open:** Sample approximately uniformly from proper \(q\)-colorings of every maximum-degree-\(\Delta\) graph in polynomial time for \(q\ge\Delta+2\).
- **Status:** Algorithms handle substantially larger palettes; the cited 2026 literature discusses an approximately \(1.809\Delta\) benchmark for unconstrained colorings.
- **Type:** theory
- **Why:** Would connect algorithmic sampling to the natural uniqueness threshold suggested by statistical mechanics.
- **Key works:** Vigoda (2000), *Improved Bounds for Sampling Colorings*; Kuchukova, Perkins, and Povill (2026), *Sampling Colorings with Fixed Color Class Sizes*, arXiv:2603.08259.
- **Related:** Statistical physics—antiferromagnetic Potts models.
